# Rails API — лабораторная работа

Небольшое Rails 8 API-приложение, подготовленное для лабораторной работы по мониторингу и сбору метрик.

Приложение содержит несколько HTTP endpoints, которые возвращают заранее заданные **stub-ответы**. Это позволяет создавать контролируемую нагрузку и наглядно наблюдать изменения метрик приложения.

## API endpoints

Основные пути:

```text
GET /api/health
GET /api/users
GET /api/products
GET /api/orders
```

Endpoints не выполняют сложной бизнес-логики и возвращают фиксированные тестовые данные. Это сделано специально для лабораторной работы, чтобы сосредоточиться на наблюдении за приложением и его метриками.

## Sidekiq

В приложении также используется **Sidekiq**.

Sidekiq выполняет роль stub/background worker: в очередь можно добавлять тестовые задачи, которые выполняются в фоне.

Это позволяет наблюдать:

* количество задач в очереди;
* количество выполненных задач;
* количество ошибок;
* время выполнения;
* состояние очередей Sidekiq.

## Prometheus

Приложение предоставляет метрики для **Prometheus**.

Метрики позволяют наблюдать работу:

* HTTP API;
* Rails-приложения;
* Sidekiq;
* background jobs.

Основная задача приложения — предоставить простой и предсказуемый источник нагрузки, чтобы изменения метрик было хорошо видно в Prometheus и Grafana.

## Запуск

Установить зависимости:

```bash
bundle install
```

Запустить Rails:

```bash
bin/rails server
```

Запустить Sidekiq:

```bash
bundle exec sidekiq
```

После запуска можно выполнять запросы к API и добавлять задачи в Sidekiq, создавая нагрузку для наблюдения за метриками.

## Назначение

Приложение является **учебным стендом**, а не полноценным production-сервисом. Его основная цель — наглядно продемонстрировать сбор и изменение метрик при работе HTTP API и фоновых задач.
