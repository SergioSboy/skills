

# Firewall: iptables/nftables





## Цель



Научиться проектировать, настраивать и диагностировать межсетевой экран Linux

с помощью nftables и понимать существующие конфигурации iptables.



## План изучения



### 1. Сетевой стек Linux



- Повторить уровни модели TCP/IP, адресацию, порты и протоколы.

- Разобрать путь пакета через локальный узел и маршрутизатор.

- Понять stateful filtering и работу conntrack.

- Изучить назначение таблиц, цепочек, правил и политик по умолчанию.



### 2. iptables



- Разобрать таблицы `filter`, `nat`, `mangle` и стандартные цепочки.

- Научиться читать вывод `iptables-save`.

- Создать базовые правила INPUT, OUTPUT и FORWARD.

- Понять порядок правил и принцип первого совпадения.



### 3. nftables



- Изучить семейства, таблицы, base chains, hooks и priorities.

- Создавать правила с помощью `nft`.

- Использовать sets, maps, counters и именованные цепочки.

- Сохранять и восстанавливать конфигурацию.



### 4. Базовая политика хоста



- Настроить default deny для входящего трафика.

- Разрешить loopback и пакеты established/related.

- Открыть только необходимые сервисные порты.

- Обеспечить безопасный доступ по SSH без блокировки текущей сессии.



### 5. Фильтрация маршрутизатора



- Включить IP forwarding.

- Настроить правила FORWARD между сетями.

- Ограничить направления и сервисы по принципу минимальных привилегий.

- Проверить обработку invalid и асимметричного трафика.



### 6. NAT



- Настроить SNAT, DNAT и masquerading.

- Реализовать публикацию внутреннего сервиса.

- Разобрать hairpin NAT и ограничения трансляции адресов.

- Проверить изменения адресов и портов с помощью tcpdump и conntrack.



### 7. Защита и ограничения



- Ограничить частоту новых соединений и ICMP без полного отключения ICMP.

- Защитить административные порты списком доверенных адресов.

- Использовать sets для управляемых списков адресов.

- Понять границы защиты firewall от DDoS.



### 8. Совместимость и миграция



- Разобрать различия iptables legacy и iptables-nft.

- Перенести тестовый набор правил с iptables на nftables.

- Проверить эквивалентность поведения, счётчики и порядок обработки.

- Подготовить безопасный план миграции и отката.



### 9. Диагностика



- Использовать counters, logging и tracing nftables.

- Анализировать трафик с помощью `tcpdump`.

- Просматривать состояния через `conntrack`.

- Отличать блокировку firewall от ошибки маршрутизации или приложения.



### 10. Эксплуатация



- Загружать правила атомарно.

- Проверять конфигурацию до применения.

- Настроить постоянную загрузку после перезагрузки.

- Документировать назначение правил и регулярно удалять устаревшие исключения.



## Практический проект



Развернуть стенд из клиента, Linux-маршрутизатора и сервера:



- default deny и минимально необходимые разрешения;

- маршрутизация между двумя подсетями;

- SNAT для исходящего трафика и DNAT для тестового сервиса;

- rate limiting административного доступа;

- вариант правил на nftables и описание миграции с iptables;

- позитивные и негативные сетевые тесты.



## Критерии завершения



- После перезагрузки применяется ожидаемый и проверенный набор правил.

- Разрешён только документированный трафик.

- NAT и stateful filtering подтверждены захватом пакетов и счётчиками.

- Конфигурация применяется атомарно и имеет проверенный сценарий отката.

- Блокировка пакета диагностируется без отключения firewall.
