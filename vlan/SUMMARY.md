## Работа с кадрами

Физический уровень передает поток бит

Как выделить в этом потоке отдельные сообщения - кадры?

## Формирование кадра

1. Сетевой уровень формирует пакет
2. Пакет передается на канальный уровень
3. К пакету прикрепляется заголовок и концевик
4. Кадр передается на физический уровень

## Метод выделения кадров

Как можно определить где в потоке начинаются и заканчиваются отдельные кадры?

- Указатель количества байт
    В начале каждого кадра указывается его длина в байтах
- Вставка байтов и битов
    Начало и конец каждого кадра отмечается специальными последовательностями байтов или бит
- Средства физического уровня
    - Преамбула (классический Ethernet)
    - Передача неиспользуемых символов избыточного кода (Fast Ethernet)

## Обнаружение и исправление ошибок

Обнаружение ошибок
- Контрольна сумма

Исправление ошибок
- Коды исправляющие ошибки

Повторная отправка данных
- Если в кадре обнаружена ошибка его можно отправить заново
- Повторная отправка кадра который не дошел до получателя

## Повторная отправка 

Без подтверждения - Проводные линии, оптоволокно

Приемник не отправляет никаких подтверждений (ACK) обратно отправителю.


С подтверждением - Беспроводные сети

Приемник обязательнно отправляет короткий кадр ACK (Acknowledge) на каждый успешно принятый кадр.


## Подуровни канального уровня

### Подуровень LLC (Logical Link Control)

- Отвечает за передачу данных (создание кадров, обработку ошибок и т.д)
- Общий для разных технологий

Предоставляемы услуги 

Мультиплексирование 
- Передача данных разных протоколов (IP, ARP, ICMP) на уровень MAC

Управление потоком
- Предотвращение затопления медленного получателя быстрым отправителем

### Подуровень MAC (MEDIA ACCESS CONTROL)

- Совместное использование разделяемой среды
- Адресация
- Специфичный для разных технологий
- Не является обязательным

Данные искажаются если несколько компьютеров передают одновременно

## Формат кадра Ethernet 

+-------------------+-----------------+----------------+-----------+--------------------+-----------+
| Преамбула + SFD   | MAC Назначения  | MAC Источника  | EtherType | Данные (IP-пакет)  | FCS (CRC) |
| 7 байт + 1 байт   | 6 байт          | 6 байт         | 2 байта   | 46 - 1500 байт     | 4 байта   |
+-------------------+-----------------+----------------+-----------+--------------------+-----------+

Preamble (Преамбула) — 7 байт

Последовательность чередующихся бит (10101010), которая используется сетевой картой приемника для синхронизации с передатчиком по частоте.

EtherType (Тип кадра) — 2 байта

Указывает, какому протоколу сетевого уровня (L3) нужно передать извлеченные из кадра данные:

- 0x0800 — IPv4

- 0x0806 — ARP

- 0x86DD — IPv6

Data / Payload (Полезная нагрузка) — от 46 до 1500 байт

- Данные, полученные с сетевого уровня (вложенный IP-пакет).

- MTU (Maximum Transmission Unit): Максимальный размер данных — 1500 байт.

FCS (Frame Check Sequence) — 4 байта

Контрольная сумма, рассчитанная отправителем по алгоритму CRC32 (Cyclic Redundancy Check).
Приемник заново рассчитывает CRC для принятого кадра; если значения не совпадают, кадр отбрасывается как поврежденный.

# MAC адреса

Используются на подуровне управления доступом в среде Media Access Control

Если у нас на канале связи несколько устройст то нам необходимо понять какому именно устройству передавать данные

Имеено для этого используются MAC адреса с помощью них мы понимаем кому именно предназначены те или инные данные

Служат для идентификации сетевых интерфейсов услов сети
- Ethernet 
- Wi-Fi

Регламентированны стандартом IEEE 802
- Длина 6 байт (48 бит)

Форма записи это шесть шестнадцатеричных чисел

## Типы MAC-адресов

Инвидуаьный (unicast)

Данные получает только один компьютер

Групповой (multicast, первый бит старшего байта адреса равен 1)

Данные получает группа компьтеров подключенных к этому адресу

Широковещательный (broadcast, все 1)

Когда данные отправляют на этот адрес его принимают все

## Уникальность MAC-адресов

В одном сегменте сети не должно быть одинаковых MAC-адресов
- Одна широковещательная среда Ethernet или Wi-Fi
- Один VLAN в коммутируемом Ethernet

Если будет два компьютера с одним MAC-адресом то один из них не будет работать
- Какой именно не регламентируется

## Способы назначения

Централизованный (по умолчанию)
- Адреса назначаются производителем оборудования
- Правила назначения описываются стандартом IEEE 802

Локальный:
- Адреса назначаются администраторами сети
- Администратор должен обеспечить уникальность

Индикатор способа назначения - второй бит старшего байта MAC-адреса
- 0 - адрес назначен центарлизованно
- 1 - адрес назначен локально

При централизованном назначении MAC-адреса должны быть униклаьными во всем мире

# Метод доступа CSMA/CD

Данные искажаются если несколько компьютеров передают одновременно
- Коллизия

## Доступ к среде

Управление доступом к среде:
- Обеспечение канала только одним отправителем

Классический Ethernet использует метод доступа к среде CSMA/CD
- Множественный доступ с прослушиванием несущей частоты и обнаружением коллизий

## Прослушивание несущей

Для того чтобы избежать коллизий компьтеры передают данные, когда среда свободна

Способом определения свободна ли среда - прослушивание основной гармоники сигнала (несущей частоты)

## Обнаружение коллизий

Два компьютера начали передачу одновременно - коллизия

Обнаружение коллизий:
- Компьютер передает и принимает сигналы одновременно
- Если принятый сигнал отличает от переданного - значит возникла коллизия

Jam-последовательность - передает компьютером при обнаружении коллизии для того, чтобы другие
компьютеры легче ее распознавали

## Передача кадра

После оконачания преамбулы комьютер начинает передать кадр

Все остальные компьютеры в сети начинют принимать кадр из записывают его в свой буфер

Первые 6 байт кадра содержат адрес получателя:
- Компьютер, который узнал свой адрес, продолжает записывать кадр
- Остальные удаляют кадр из буфера

Неразборчивый режим (promiscusous mode):
- Адаптер принимает все кадры в сети, не зависимо от MAC-адреса назначения

## Период передачи 
Если в середе нет несущей частоты, то компьтер может начинать передачу данных

Межкадровый интервал:
- 9,6 мкс
- Предострващает монополию
- Приведение сетевых адаптеров в исходное состояние

## Период конкуренции
Если компьютер начал передавать данные и обнаружил коллизию, то он делает паузу

Длительность паузы: L * 512 битовых интервалов

## Как коммутатор узнает MAC-адреса которые подключены к нему?

Для этого используетя алгоритм обратного обучения


## Как коммуатор передает данные?

Для этого используется алгоритм прозрачного моста

Мост - устройство для объединения несколькоих сетей
- Предшественник коммутатора
- Алгоритм прозрачного моста

Прозрачный мост
- Не заметен для сетевых устройств
- Не требует настройки

## Коммутатор и коллизии

К каждому порту коммутатора подключен только один компьютер/коммутатор
- Полный дуплекс - коллизии не возникают
- Полудуплекс - коллизия может возникнуть ессли компьтер и коммутатор одновременно решат передавать данные

К порту коммутатора подключен концентратор
- Общая среда передачи, подключенная к порту коммутатора
- Коллизии возникают, как в классическом Ethernet
